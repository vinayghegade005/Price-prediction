# Price-prediction
# California Housing Price Prediction

## Project Overview

This project demonstrates a machine learning workflow for predicting **California housing prices** using the **California Housing Dataset** from Scikit-learn. The notebook covers data exploration, preprocessing, model training, evaluation, and visualization of prediction results.

The project was developed as part of an academic assignment to understand regression techniques and evaluate machine learning model performance.

---

## Features

* Load the California Housing dataset
* Perform exploratory data analysis (EDA)
* Split the dataset into training and testing sets
* Build regression models using Scikit-learn
* Apply feature preprocessing with pipelines
* Evaluate model performance using standard regression metrics
* Visualize Actual vs. Predicted values and Residual plots
* Compare different regression approaches

## Dataset

**Dataset:** California Housing Dataset

The dataset is available directly from the Scikit-learn library and contains housing-related features such as:

* Median Income
* House Age
* Average Rooms
* Average Bedrooms
* Population
* Average Occupancy
* Latitude
* Longitude

**Target Variable:**

* Median House Value

## Machine Learning Workflow

1. Import required libraries
2. Load the dataset
3. Explore and understand the data
4. Split data into training and testing sets
5. Build regression models
6. Train the models
7. Make predictions
8. Evaluate model performance using:

## Model Evaluation

The notebook evaluates the regression models using:

* Mean Squared Error (MSE)
* Mean Absolute Error (MAE)
* R² Score

* Actual vs Predicted Scatter Plot
